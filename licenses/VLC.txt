VLC's engine in this package
============================

This copy of LVP includes the playback engine of VLC media player
{version}: libvlc, libvlccore, their plugins and VLC's Lua scripts, taken
from VideoLAN's official release. VLC's own interface is not included.

The complete source of VLC {version} is available from VideoLAN:

  https://download.videolan.org/pub/videolan/vlc/{version}/vlc-{version}.tar.xz

and the source of the third-party libraries it is built with:

  https://download.videolan.org/pub/contrib/

Replacing the engine
--------------------

LVP loads libvlc at run time, so it works with any build of libvlc 3. Set
the LVP_LIBVLC environment variable to the folder that contains another
libvlc, or replace the libvlc files in this package.
